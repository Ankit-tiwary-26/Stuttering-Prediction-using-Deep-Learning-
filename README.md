# Stuttering Detection Using Deep Learning

This project focuses on detecting stuttered speech using deep learning techniques on audio data. The system extracts MFCC (Mel Frequency Cepstral Coefficients) features from speech signals and uses a CNN-LSTM architecture to classify speech as either normal or stuttered. The model was trained on mixed-gender voice datasets and evaluated separately on male, female, and mixed test sets to analyze performance across different speaker groups.

The project includes audio preprocessing, feature extraction, model training, evaluation, and deployment using Streamlit for real-time prediction. It aims to support automatic speech fluency analysis and assist in speech disorder research using AI-based solutions.
